# Модуль фитнес-трекера step-by-step (Go)

Учебный проект: программный модуль для фитнес-гаджета, который обрабатывает данные об активности пользователя, парсит строки и рассчитывает потраченные калории, дистанцию и скорость.

**Автор:** Полина Пятышина  
**Стек:** Go (стандартная библиотека: `time`, `strconv`, `strings`, `log`)

## Что делает модуль

Программа принимает на вход строки с данными о прогулках и тренировках, валидирует их и производит расчеты на основе веса и роста пользователя. Модуль разделен на два логических пакета:

- **Пакет `daysteps`**: отвечает за учет дневной активности (ходьба). Парсит строку формата `"678,0h50m"`, считает пройденную дистанцию и потраченные калории.
- **Пакет `spentcalories`**: отвечает за расчет калорий в зависимости от вида активности (бег или ходьба). Вычисляет среднюю скорость, дистанцию и итоговые затраты энергии.

## Что было сделано

- Написаны функции парсинга строковых данных (`parsePackage`, `parseTraining`) с обработкой ошибок формата и отрицательных значений.
- Реализован расчет длины шага, дистанции (в км) и средней скорости.
- Реализован расчет сожженных калорий отдельно для ходьбы и бега с использованием корректирующих коэффициентов.
- Сформирован вывод информации о дневной активности и о конкретной тренировке.
- Добавлена обработка ошибок (возврат пустых строк или ошибок при некорректном вводе).

## Как запустить

Для запуска основной функции модуля выполни в корне проекта:

```bash
go run ./cmd/tracker
```

Для проверки корректности расчетов и парсинга запусти тесты (если они добавлены в проект):


Программа рассчитывает параметры на основе переданных данных. 
Пример вывода для тренировки (бег):

```text
Тип тренировки: Бег
Длительность: 0.75 ч.
Дистанция: 10.00 км.
Скорость: 13.34 км/ч
Сожгли калорий: 18621.75
```
